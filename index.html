Buobpack Scan Factures

Lecture OCR · CHF / EUR · Export CSV

1. Photographier ou choisir une facture

Sélectionne une photo pour commencer.

La première reconnaissance peut prendre un peu de temps. Le moteur OCR se charge depuis Internet, mais l'image est analysée sur ton appareil. Vérifie toujours les chiffres reconnus.

2. Vérifier les informations

Le nom proposé par OCR doit être confirmé.

TVA non indiquée : aucune TVA déductible ne peut être déterminée automatiquement.

3. Exporter

Sur iPhone, utilise le menu de partage ou l'application Fichiers pour enregistrer le CSV dans Dropbox. L'export contient une ligne par facture, avec les montants dans leur devise d'origine : aucune conversion EUR/CHF automatique.
